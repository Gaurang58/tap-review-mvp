# Tap Review MVP

Initial Next.js application scaffold for an NFC + QR Google review analytics MVP.

This branch only contains the application foundation. It does not include Supabase, authentication, redirect routes, dashboards, API integrations, environment variables, secrets, or business logic yet.

## Local Setup

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Checks

Run linting:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```
